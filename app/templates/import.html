Accepted layout

bundle.zip
├── patients.csv          (or .xlsx / .json)
├── CF-P001/              (folder per patient ID or name)
│   ├── discharge.pdf
│   └── aadhaar.jpg
├── CF-P002_bill.pdf      (or ID as file prefix)
└── queries/
    └── CF-P001_letter.pdf

Column names are matched loosely: patient_id / id / uhid, name, phone / mobile, email, insurer / tpa, policy_no, claim_no, hospital, admission_date, assigned_agent.

Each new patient gets a login (their ID in lower case without the dash).

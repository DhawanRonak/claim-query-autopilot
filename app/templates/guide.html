Start here: a 5-minute tour

Claim Query Autopilot reads an insurer's query letter the moment it lands in a patient's locker, checks what's already there, and messages the patient with only what's missing. No one clicks anything in between.

Try it

  1. Get a sample letter. Download one from sample_queries on GitHub (file names start with the patient ID, e.g. CF-P001_star_query.pdf), or use your own.
  2. Upload it. Log in as admin, open that patient, and use Add insurer query letter.
  3. Watch it work. Within seconds the page shows every point in the letter, what it maps to, and the decision: Already in locker Ask patient Hospital team Agent review.
  4. Read the message. Scroll to Messages: the email and WhatsApp text sent to the patient, each item with a plain-language "why".
  5. Be the patient. Log in as p001: see what's pending, upload a document, and watch the item tick off.
  6. Check access. As agent.priya, open CF-P006: it's blocked and logged in admin's Access log.
  7. Bulk load. Admin → Import accepts a ZIP of patient profiles, documents and query letters.
